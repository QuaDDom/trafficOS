# TrafficOS — Brand kit 1.0

Una ciudad viva. Cada decisión, conectada.

## Concepto
El símbolo representa una intersección en T recortada en una señal. Sus esquinas y las letras comparten cortes de 45°. Las marcas internas remiten a carriles; el naranja identifica movimiento y acción.

## Archivos
- logo-light: horizontal para asfalto y fondos oscuros.
- logo-dark: horizontal para blanco o papel claro.
- logo-black / logo-white: una sola tinta, fondos contrastantes.
- symbol: avatar y símbolo aislado en fondo oscuro. symbol-dark / symbol-white: una tinta.
- wordmark: lettering sin símbolo; stacked: composición vertical en fondo oscuro.
- app-icon: iconos con fondo, 32/180/192/512 px.
- social-cover: portada 1200 × 630 px.
- Los PNG de logos tienen fondo transparente. Los SVG de logos contienen trazados, no texto ni fuentes externas. La portada usa texto de sistema.

## Uso
Mantener al menos 16 unidades libres alrededor del lockup horizontal de 472 × 80. Ancho recomendado mínimo: 142 px; símbolo aislado: 24 px (favicon simplificado para tamaños menores). No deformar, rotar, agregar sombras, cambiar colores o colocar sobre imágenes sin una superficie uniforme. Usar SVG en web e impresión vectorial y PNG en herramientas que lo requieran.

## Colores
- asphalt: #1A1D18
- signal: #F17846
- chalk: #E8E5D6
- sage: #B8C69A
- concrete: #858B79

El naranja es acento de marca. El estado de semáforos siempre incluye texto o forma, además del color.

## Tipografía y voz
El lettering del logo es dibujo vectorial propio. Barlow Condensed 600/700 para titulares; IBM Plex Mono 400 para datos; Arial/sans-serif para lectura extensa. Las fuentes de interfaz se distribuyen en sus paquetes @fontsource con sus licencias respectivas; no forman parte de estos trazados.
Voz: directa, urbana y comprensible. Frases cortas, verbos concretos y decisiones explicables. Tagline: Streets alive. Systems connected.

## Fuente editable
Generar desde scripts/build-brand.mjs con npm run brand:build. Identidad original dibujada para este proyecto.
